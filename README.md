# WAN Network Design with Static Routing (Cisco Packet Tracer)

## Overview
This project simulates a small WAN network connecting three LANs that represent company offices in different locations. The network was implemented in Cisco Packet Tracer using IPv4 subnetting and static routing between routers.

## Network Structure
Each location includes:
- 1 Router
- 1 Switch
- 1 PC

Routers are interconnected through point-to-point WAN links.

## IP Addressing
LAN networks use **/27 subnetting**, while WAN links use **/30 subnetting** for efficient address usage.

## Technologies Used
- Cisco Packet Tracer
- IPv4 Addressing
- Subnetting
- Static Routing
- Network troubleshooting (ping, traceroute)

## Testing
Connectivity was verified using `ping` between PCs located in different LANs.
